## 🔍  Project Highlights – Loan Prediction ML Project ## 

📌 Objective: Built a Machine Learning model to predict whether a loan will be approved based on applicant details like income, education, credit history, etc.

🧹 Data Cleaning:

Handled missing values using appropriate imputation techniques.

Converted categorical variables to numerical using label encoding and one-hot encoding.

📊 Exploratory Data Analysis (EDA):

Analyzed distributions of applicant income, loan amount, and credit history.

Identified key correlations and visualized them using seaborn and matplotlib.

📈 Modeling & Evaluation:

Implemented Logistic Regression, Gradient Boosting, Decision Tree, and Random Forest models.


Evaluated models using accuracy, precision, recall, and confusion matrix.

✅ Best Model: Achieved high prediction accuracy using Logistic Regression and Gradient Boosting Classifier.

💼 Business Insight:

Found credit history and applicant income to be crucial features in predicting loan approval.

Model assists in automating and improving efficiency in loan disbursal decisions.

💾 Tools & Libraries:

Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Jupyter Notebook.
